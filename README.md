# Awady Music

Awady Music is a free, privacy-friendly music streaming application for Android and iOS featuring background playback with lock-screen controls, offline downloads, synced lyrics, local playlist management, and personal listening statistics — with no accounts, no ads, no telemetry, and no external servers.

Based on Freebify by govu — https://github.com/govu/freebify (licensed under GNU GPL v3 with Freebify Attribution Clause).
